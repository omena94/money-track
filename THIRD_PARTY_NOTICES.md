# ALL SET / all-set-tw

本專案參考 [all-set-tw](https://github.com/TedLin1993/all-set-tw) 的 UI 設計、色彩與功能。原私人版本曾移植其集保（TDCC）協定程式，公開版已移除該部分；以下保留原專案授權聲明。

銀行官方 App 圖像未納入公開版本；本機安裝素材不適用本專案 MIT 授權。其他套件依各自隨附授權使用，版本見 npm 與 Cargo lockfiles。
